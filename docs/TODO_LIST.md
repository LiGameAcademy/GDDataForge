## 技术方案

### UI 框架
- Godot Control 节点系统
- Tree 节点用于表格
- 自定义 Cell 编辑器

### 数据流
```
CSV/JSON 文件 ←→ DataLoader ←→ 内存模型 ←→ UI 表格
                         ↓
                   TableType/ModelType
```

### 关键类设计
- `DataTableEditor`: 主编辑器面板
- `TableView`: 表格视图组件
- `CellEditor`: 单元格编辑器
- `DataValidator`: 数据校验器
- `ImportExport`: 导入导出器
